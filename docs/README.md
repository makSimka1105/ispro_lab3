## 🔧 Модули библиотеки

### 🔵 `circle.py` — Утилиты для круга

Работа с окружностями и кругами.

**Функции:**
- `area(r)` — вычисляет площадь круга
  - `r` — радиус круга
- `perimeter(r)` — вычисляет длину окружности
  - `r` — радиус круга

**Формулы:**
- Площадь: `S = π × r²`
- Периметр: `P = 2 × π × r`

---

### 🟦 `square.py` — Утилиты для квадрата

Расчёты для квадратов.

**Функции:**
- `area(a)` — вычисляет площадь квадрата
  - `a` — длина стороны квадрата
- `perimeter(a)` — вычисляет периметр квадрата
  - `a` — длина стороны квадрата

**Формулы:**
- Площадь: `S = a²`
- Периметр: `P = 4 × a`

---

### 🟩 `rectangle.py` — Утилиты для прямоугольника

Расчёты для прямоугольников.

**Функции:**
- `area(a, b)` — вычисляет площадь прямоугольника
  - `a` — длина прямоугольника
  - `b` — ширина прямоугольника
- `perimeter(a, b)` — вычисляет периметр прямоугольника
  - `a` — длина прямоугольника
  - `b` — ширина прямоугольника

**Формулы:**
- Площадь: `S = a × b`
- Периметр: `P = 2 × (a + b)`

---

### 🔺 `triangle.py` — Утилиты для треугольника

Расчёты для треугольников.

**Функции:**
- `area(a, h)` — вычисляет площадь треугольника
  - `a` — основание треугольника
  - `h` — высота, проведённая к основанию
- `perimeter(a, b, c)` — вычисляет периметр треугольника
  - `a` — первая сторона треугольника
  - `b` — вторая сторона треугольника
  - `c` — третья сторона треугольника

**Формулы:**
- Площадь: `S = (a × h) / 2`
- Периметр: `P = a + b + c`
