# Отчет о тестировании

## 1. Цели и задачи тестирования

Основная цель – проверить корректность работы функций для вычисления площади и периметра геометрических фигур. В задачи входит:

- Убедиться в правильности расчетов площади для квадратов, прямоугольников, треугольников и кругов
- Проверить корректность вычисления периметра для всех фигур
- Протестировать поведение функций на граничных значениях (нулевые значения, дробные числа, большие значения)
- Удостовериться в стабильности работы при различных входных параметрах

## 2. Описание тестируемого продукта

Проект представляет собой набор модулей на Python для расчета геометрических параметров. Каждый модуль отвечает за одну фигуру и содержит две основные функции:

- **square.py** – вычисление площади и периметра квадрата
- **rectangle.py** – вычисление площади и периметра прямоугольника
- **triangle.py** – вычисление площади и периметра треугольника
- **circle.py** – вычисление площади и длины окружности

Все функции принимают числовые параметры (float) и возвращают результаты в виде чисел с плавающей запятой.

## 3. Область тестирования

Тестирование охватывает следующие компоненты:

- Обработка положительных значений
- Обработка нулевых значений
- Обработка дробных чисел
- Обработка отрицателных значений 

## 4. Стратегия тестирования

Используется функциональное тестирование с применением модульных тестов. Для каждой функции разработаны тестовые случаи, покрывающие:

- **Нормальные случаи** - типичные значения в рамках ожидаемого диапазона
- **Граничные значения** - нулевые значения, минимальные и максимальные значения
- **Значения-эквиваленты** - дробные числа, целые числа, единичные значения
- **Ошибочные вводные данные** -отрицательные вводные данные коректно возвращают ошибку 

Тестирование выполняется с использованием фреймворка unittest, встроенного в Python.

## 5. Критерии приемки

Тестирование считается успешным при выполнении следующих условий:

- Все тестовые случаи должны пройти без ошибок
- Результаты функций должны совпадать с ожидаемыми значениями (с учетом точности для операций с числами с плавающей запятой)
- Функции должны корректно обрабатывать нулевые и граничные значения
- Для функций, работающих с числом π, используется сравнение с точностью 5 знаков

## 6. Ожидаемые результаты

### Квадрат (square.py)

Ожидается, что функция `area()` вернет квадрат стороны, а `perimeter()` вернет четыре умноженные на сторону. Предусмотрены 12 тестовых случаев для проверки различных сценариев.

### Прямоугольник (rectangle.py)

Функция `area()` должна возвращать произведение длины и ширины, `perimeter()` – удвоенную сумму. Разработано 12 тестовых случаев.

### Треугольник (triangle.py)

Функция `area()` вычисляет площадь как произведение основания и высоты, поделенное на два. Функция `perimeter()` суммирует три стороны. Всего 14 тестовых случаев.

### Круг (circle.py)

Функция `area()` возвращает π × r², `perimeter()` возвращает 2π × r. Разработано 14 тестовых случаев с использованием assertAlmostEqual для сравнения.
